# 🌍 Gen-AI-Translator

An AI-powered language translator that translates text between multiple languages in real-time using Generative AI.

Type in English, get output in Hindi, Punjabi, French, Spanish, and many more languages instantly.

## ✨ Features
- Translate text in 50+ languages
- AI-powered accurate translation
- Clean and simple user interface
- Fast and real-time results
- Copy translated text in one click
- Easy to run locally

## 🛠️ Tech Stack
- **Language:** Python
- **AI:** Generative AI / Google Translate API
- **Frontend:** HTML, CSS / Streamlit
- **Libraries:** googletrans, deep-translator
